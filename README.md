# GHG Empire — Telegram Mini App

مشروع بداية قابل للنشر للعبة تعدين افتراضية GHG. الواجهة عربية RTL ومبنية على الصورة المرجعية المرفقة، مع API وقاعدة بيانات.

## ما الذي يعمل في هذا الإصدار؟
- تسجيل المستخدم عبر Telegram WebApp `initData` والتحقق من توقيعه على الخادم.
- تعدين تراكمي من وقت آخر تحديث، مع رصيد معلّق وزر Claim.
- مستويات وخبرة وترقية سرعة التعدين.
- مهمة زيارة يومية (يجب إضافة إعادة ضبط يومية قبل الإطلاق العام).
- روابط إحالة أساسية.
- لوحة إدارة API لإحصائيات المستخدمين وتعديل الرصيد.
- مسار توثيق TON: يرسل المحفظة تعليق `GHG_VERIFY_<telegram_id>`، ثم يبحث الخادم عن معاملة واردة بالمبلغ المطلوب ويمنع إعادة استخدام hash.

## تشغيل محلي
1. ثبّت Python 3.12+.
2. انسخ `.env.example` إلى `.env` واملأ القيم.
3. `pip install -r requirements.txt`
4. `uvicorn app.main:app --reload`
5. افتح `http://localhost:8000/health` للتأكد من عمل الخادم.

## إعداد Telegram
- أنشئ بوتًا عبر BotFather واحصل على `BOT_TOKEN`.
- اضبط `BOT_USERNAME`.
- انشر التطبيق على HTTPS عام، ثم اضبط `WEBAPP_URL`.
- اربط زر القائمة أو زر `/start` بفتح Web App.
- استبدل قيم النطاق في `tonconnect-manifest.json` بنطاقك الحقيقي.
- أضف Telegram user ID الخاص بك إلى `ADMIN_IDS`.

## إعداد TON
- `TON_RECEIVE_ADDRESS` مضبوط مبدئيًا على العنوان الذي زوّدني به المستخدم.
- أضف مفتاح TON Center API إلى `TONCENTER_API_KEY`.
- المبلغ الافتراضي 0.05 TON = 50,000,000 nanoton.
- لا تطلق الدفع الحقيقي قبل اختبار شبكة TON، التعليقات، تأكيد المعاملات، والتعامل مع المعاملات المتأخرة أو الملغاة.
- هذا الإصدار يستخدم TON Center v2 كآلية تحقق أولية؛ يوصى قبل الإطلاق العام باستخدام webhook/indexer موثوق، وفحص نهائية المعاملة، ومطابقة عنوان المستلم والمبلغ والـ comment بدقة.

## لوحة الإدارة
- افتح `/admin` من داخل Telegram بحساب موجود ضمن `ADMIN_IDS`.
- نقاط الإدارة تتحقق من Telegram initData وتوقيعه على الخادم، وليس من رقم مستخدم يرسله العميل.

## مهم قبل الإطلاق العام
هذا مشروع أساس قابل للتشغيل وليس خدمة مستضافة أو مدققة أمنيًا. يلزم إعداد HTTPS، النطاق، BotFather، أسرار البيئة، نسخ احتياطي، حدود طلبات، سجلات، مراجعة أمنية، اختبارات دفع TON، وسياسة خصوصية وشروط استخدام. لا تضع BOT_TOKEN أو مفاتيح API داخل ملفات الواجهة أو المستودع.
